# 开发进度日志（模板）

> ⚠️ 本文件为**追加式**记录，**禁止覆盖历史内容**。
> 每当完成一个有实质产出的对话轮次，必须追加一条记录。

## 日志格式约定

每条记录包含：时间戳 / 本次目标 / 完成内容 / 产出文件 / 关键决策及理由 / 遗留问题下一步

**禁止**只写"已完成"。必须写清：完成了什么、在哪、依据是什么。
**必须**记录"关键决策及理由"——三个月后回头看，理由比结论重要。
**必须**写"遗留问题 / 下一步"——这是下次对话的上下文入口。

## 记录要点提醒

| 要点 | 说明 |
|---|---|
| 时间戳必填 | 便于回溯时间线 |
| 完成内容要具体 | 三个月后能看懂当时做了什么 |
| 决策必记理由 | 结论会过时，理由不会 |
| 阻塞项标 ⚠️ | 下次对话优先处理 |
| 写清下一步 | 下次对话的上下文入口 |
| 不覆盖历史 | 用追加，不用重写 |
