# 电气安全与异常保护核对表

> 上位机软件虽不直接控制强电，但通过协议间接控制现场设备。
> **一个错误的写操作可能导致产线停机、设备损坏或人员伤害。** 本表必须逐条确认。

---

## 第一部分：人身安全

- [ ] 01 是否存在运动部件（电机、气缸、机械臂、传送带）由软件控制
- [ ] 02 急停按钮状态是否被上位机采集并显示
- [ ] 03 急停触发时上位机行为已定义：☐ 停止下发指令 ☐ 弹窗告警 ☐ 禁止所有写入 ☐ 记录日志
- [ ] 04 安全门 / 光栅 / 安全继电器状态是否采集
- [ ] 05 安全门打开时的软件行为已定义
- [ ] 06 是否存在软件可绕过硬件的安全回路（必须禁止）
- [ ] 07 软件是否可能下发与安全联锁冲突的指令
- [ ] 08 手动模式下是否有速率/范围限制
- [ ] 09 是否需"双手操作"确认的高危动作
- [ ] 10 是否存在高压部件？软件侧是否有警示标识
- [ ] 11 是否涉及高温部件？是否有超温报警
- [ ] 12 危险操作是否有明确的操作提示与范围说明
- [ ] 13 现场人员误操作的可能性是否评估
- [ ] 14 是否需要操作权限分级（防止非授权操作）
- [ ] 15 是否有"一键停止/急停"的软件按钮

## 第二部分：设备保护

- [ ] 16 所有写入参数是否设定了合法上下限
- [ ] 17 超出范围的写入是否被拒绝并告警
- [ ] 18 是否校验写入的数据类型与长度匹配
- [ ] 19 高危参数是否需二次确认弹窗（显示旧值→新值）
- [ ] 20 高危参数写入是否需输入确认文本（防误触）
- [ ] 21 写入后是否回读校验
- [ ] 22 是否存在"运行中禁止修改"的参数？是否已联锁
- [ ] 23 是否存在修改后需重新启动生效的参数？是否有提示
- [ ] 24 是否存在写 EEPROM 次数限制的参数？是否做写入频率限制
- [ ] 25 通信中断时上位机是否停止发送控制指令
- [ ] 26 上位机崩溃时设备是否有硬件看门狗保护
- [ ] 27 看门狗喂狗周期与超时阈值是否匹配
- [ ] 28 上电初始化顺序是否有要求（先使能哪个设备）
- [ ] 29 断电顺序是否有要求（先停哪个设备）
- [ ] 30 是否存在需要"软停机"而非"硬断电"的设备
- [ ] 31 频繁启停是否有次数限制
- [ ] 32 是否存在过流/过压/过热保护需要软件配合

## 第三部分：通信异常保护

- [ ] 33 通信中断后设备的安全状态已定义
- [ ] 34 通信中断后的重连策略已定义（指数退避）
- [ ] 35 重连期间是否暂停下发控制指令
- [ ] 36 重连后是否需要重新初始化（握手、使能、订阅）
- [ ] 37 重连后是否需要状态同步（读取当前设备状态）
- [ ] 38 校验错误的重试策略（次数、间隔、上限）
- [ ] 39 连续超时后的处理（标记设备故障、告警）
- [ ] 40 单设备故障是否隔离（不影响其他设备）
- [ ] 41 是否有"设备故障"状态的显式显示
- [ ] 42 数据是否可能被误认为有效（坏值过滤）
- [ ] 43 数据质量码（Quality）是否被检查并使用
- [ ] 44 是否有数据超范围的数据有效性检查
- [ ] 45 是否有数据跳变的异常检测（如突变 10 倍）
- [ ] 46 慢变信号是否有变化率限制报警

## 第四部分：软件健壮性保护

- [ ] 47 全局异常捕获是否已实现（ThreadException / UnhandledException）
- [ ] 48 捕获后是否提供诊断信息导出
- [ ] 49 是否禁止使用空 catch 吞掉异常
- [ ] 50 UI 线程是否有阻塞操作（会导致界面假死）
- [ ] 51 是否有死锁风险（`.Result` / `.Wait()` / 同步 Invoke）
- [ ] 52 长耗时操作是否有进度提示与取消能力
- [ ] 53 是否有内存泄漏风险（事件未取消订阅）
- [ ] 54 是否有句柄泄漏风险（IDisposable 未释放）
- [ ] 55 是否处理了磁盘满的情况
- [ ] 56 是否处理了数据库锁定/损坏
- [ ] 57 是否处理了配置文件损坏（回退到默认）
- [ ] 58 是否处理了配置文件缺失
- [ ] 退出时是否等待在途任务完成
- [ ] 60 退出时是否刷盘并关闭数据库
- [ ] 61 是否有防止重复启动的机制（互斥体）

## 第五部分：操作安全

- [ ] 62 关键操作是否有操作日志（谁、何时、改什么、旧值新值、结果）
- [ ] 63 操作日志是否不可篡改（只追加）
- [ ] 64 是否有操作确认流程（高危操作二次确认）
- [ ] 65 是否有操作超时自动登出
- [ ] 66 是否有参数导入导出功能（便于恢复）
- [ ] 67 是否有一键恢复到出厂参数的功能
- [ ] 68 参数修改是否需说明原因
- [ ] 69 是否提供"预演/仿真"模式（不实际下发）
- [ ] 70 是否有操作前状态检查（如检查设备是否就绪）

## 第六部分：报警与告警

- [ ] 71 报警分级定义（提示/警告/严重/致命）
- [ ] 72 每级报警的视觉与听觉表现已定义
- [ ] 73 报警是否需要人工确认（Ack）
- [ ] 74 未确认报警是否持续提示
- [ ] 75 报警是否有声光输出（现场噪音环境下需大音量）
- [ ] 76 报警是否记录历史（含时间、设备、内容、确认人）
- [ ] 77 报警是否有消音功能
- [ ] 78 是否有报警抑制（避免刷屏）
- [ ] 79 通信故障是否产生报警
- [ ] 80 报警阈值是否可配置
- [ ] 81 是否有报警恢复通知
- [ ] 82 多条报警并发时的处理优先级

## 第七部分：数据安全与合规

- [ ] 83 是否涉及产品质量数据？是否需防篡改
- [ ] 84 数据是否需符合追溯要求（ISO/GMP/汽车行业）
- [ ] 85 是否需审计追踪（Audit Trail）
- [ ] 86 是否涉及个人信息？是否符合隐私要求
- [ ] 是否需电子签名（FDA 21 CFR Part 11 类要求）
- [ ] 88 数据备份策略是否已定义
- [ ] 89 数据恢复流程是否已验证
- [ ] 90 是否有环境限制（禁止 U 盘、禁止外网）

## 第八部分：环境与部署安全

- [ ] 91 是否需要管理员权限运行
- [ ] 92 是否有杀毒软件干扰风险（文件锁定、误杀）
- [ ] 93 是否已加入杀毒白名单
- [ ] 94 防火墙端口是否已开放
- [ ] 95 是否存在不必要的网络暴露（调试端口）
- [ ] 96 是否有远程访问安全措施（VPN/密码）
- [ ] 97 是否存在硬编码密码
- [ ] 98 配置文件中的敏感信息是否加密
- [ ] 99 是否有日志泄露敏感信息的风险
- [ ] 100 是否关闭了生产环境不需要的调试功能

## 风险等级评定

对以上每条，标记风险等级：

| 等级 | 含义 | 处理要求 |
|---|---|---|
| 🔴 致命 | 可能导致人身伤害或重大设备损坏 | 必须实现防护，无例外 |
| 🟠 严重 | 可能导致生产中断或数据丢失 | 必须实现防护 |
| 🟡 一般 | 影响使用体验或效率 | 建议实现 |
| 🟢 提示 | 优化项 | 视时间安排 |
