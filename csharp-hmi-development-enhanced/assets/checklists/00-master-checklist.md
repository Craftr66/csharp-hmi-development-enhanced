# 上位机软件开发 主核对表（Master Checklist）

> 使用方法：项目启动时逐条过一遍；设计评审时过一遍；联调前过一遍；验收前过一遍。
> 每项状态：`☐ 未确认` / `✅ 已确认` / `❌ 不适用` / `⚠️ 待确认（阻塞项）`
>
> **⚠️ 项为阻塞项，未清零不得进入编码阶段。**

---

## A. 项目与商务类

- [ ] A01 项目名称、编号、客户单位已明确
- [ ] A02 交付形态明确：源码 / 可执行 + 安装包 / 含硬件 / 含服务
- [ ] A03 交付时间节点与里程碑已确认
- [ ] A04 验收标准与验收方式已书面确认
- [ ] A05 客户现场是否可远程协助（VPN / 向日葵 / TeamViewer）
- [ ] A06 是否需要驻场调试？驻场时长与人员
- [ ] A07 质保期与后期维护责任边界
- [ ] A08 是否需要提供培训？培训对象与时长
- [ ] A09 软件许可与第三方库授权是否合规（商业库授权费谁承担）
- [ ] A10 客户是否有 IT 安全要求（禁止外网、禁止 U 盘、需杀毒白名单）

## B. 硬件类

- [ ] B01 所有待接入设备的完整清单（名称、型号、厂家、数量）
- [ ] B02 每台设备的通信接口（RS232/RS485/以太网/CAN/USB/GPIB）
- [ ] B03 每台设备的通信协议（Modbus/S7/OPC UA/自定义/SCPI）
- [ ] B04 每台设备的通信参数（波特率/校验/IP/端口/站号）
- [ ] B05 设备是否支持同时被多个客户端连接？
- [ ] B06 设备的最大连接数限制
- [ ] B07 设备的命令响应时间（最慢多少 ms？决定超时设置）
- [ ] B08 设备是否有开机初始化序列（如需要握手、使能、复位）？
- [ ] B09 设备是否有"写后需延时生效"的寄存器？
- [ ] B10 设备固件版本是否统一？不同版本协议是否有差异？
- [ ] B11 是否有已停产/淘汰设备需要特殊兼容？
- [ ] B12 工控机/服务器配置（CPU/内存/硬盘/串口数量/网口数量）
- [ ] B13 显示器分辨率与是否多屏
- [ ] B14 是否使用触摸屏？触摸精度要求
- [ ] B15 是否需要条码枪/扫码器？接口与格式
- [ ] B16 是否需要打印机（标签/报表）？型号与驱动
- [ ] B17 是否需要看板/大屏输出？
- [ ] B18 是否使用 USB 转串口？转换器型号（决定端口漂移处理）
- [ ] B19 是否存在虚拟串口/仿真器？与实机差异
- [ ] B20 是否使用 IO 卡 / 运动控制卡 / 数据采集卡？厂家 SDK 是否获取
- [ ] B21 是否需要 UPS？断电后处理策略
- [ ] B22 硬件是否已全部到货？未到货设备如何打桩
- [ ] B23 是否有备用设备用于开发调试

## C. 电气与环境类

- [ ] C01 供电电压与是否需隔离（现场干扰大时需光耦/磁耦隔离）
- [ ] C02 接地方式（设备地与计算机地是否等电位）
- [ ] C03 是否需要屏蔽线、屏蔽层单端接地
- [ ] C04 通信线缆规格与最长距离（RS485 ≤1200m，RS232 ≤15m）
- [ ] C05 RS485 总线拓扑（手拉手，禁止星型）、终端电阻（两端 120Ω）
- [ ] C06 总线设备数量与总线负载能力
- [ ] C07 现场电磁干扰源（变频器、伺服、焊机、大功率继电器）
- [ ] C08 是否需要通信隔离器 / 中继器 / 浪涌保护器
- [ ] C09 现场温湿度、粉尘、油污、振动、腐蚀性气体
- [ ] C10 工控机安装方式（机柜/桌面/壁挂），散热条件
- [ ] C11 网线规格与走线距离（≤100m，超长需交换机中继）
- [ ] C12 是否与强电同槽走线（会导致通信干扰）
- [ ] C13 相序与电源质量（是否需要稳压）
- [ ] C14 设备金属外壳是否接大地
- [ ] C15 是否有防雷要求（户外/跨建筑布线）

## D. 通信协议类

- [ ] D01 协议文件/手册是否已获取（寄存器表、报文格式）

- [ ] D11 重试次数与重试间隔

- [ ] D13 是否需要应用层心跳？周期与超时阈值
- [ ] D14 断线重连策略？重连后是否需要重新初始化
- [ ] D15 是否支持批量读取？单次最大数据量
- [ ] D16 写入操作的权限与范围限制
- [ ] D17 是否有时序要求（发送间隔、最小轮询周期）
- [ ] D18 协议版本与固件版本对应关系
- [ ] D19 是否有实测报文样例（用于逆向验证）
- [ ] D20 上下位机协议文档是否双方签字确认
