# 交付与验收核对表

---

## 第一部分：开发阶段自检

### 1.1 代码质量

- [ ] 无编译警告（或警告已逐条评估）
- [ ] 无 TODO / HACK / FIXME 遗留（或已登记台账）
- [ ] 无注释掉的死代码
- [ ] 无硬编码的 IP / 路径 / 密码 / 端口
- [ ] 无 `catch (Exception) { }` 空捕获
- [ ] 无 UI 线程阻塞调用（`.Result` / `.Wait()` / `Thread.Sleep`）
- [ ] 所有 `IDisposable` 已正确释放
- [ ] 所有事件订阅已对应取消订阅
- [ ] 命名符合规范（类 PascalCase、私有字段 _camelCase）
- [ ] 关键类与公有方法有 XML 注释
- [ ] 复杂算法有实现说明注释

### 1.2 架构检查

- [ ] 依赖方向单向，UI 层未直接访问数据库/串口
- [ ] 通信层已抽象为接口，可替换
- [ ] 存在 SimulatedTransport 可无硬件运行
- [ ] 配置全部外置
- [ ] 单设备故障已隔离
- [ ] 有全局异常兜底
- [ ] 有优雅退出流程

### 1.3 单元测试（建议）

- [ ] Domain 层核心算法有单测
- [ ] 协议解析（CRC、拆包、字节序）有单测
- [ ] 地址转换有单测
- [ ] 测试覆盖率 ≥ ___ %
